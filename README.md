# Weather Prediction ML

Проект по прогнозированию ощущаемой температуры (`apparent_temperature`)
на основе исторических погодных данных Open-Meteo.

Основная цель проекта — построить полный ML-пайплайн:
от загрузки и подготовки данных до обучения модели,
оценки качества и демонстрации результата через Flask-приложение.

## Интерфейс приложения

![Интерфейс Weather Prediction ML](images/app_interface.png)

## Что реализовано

- загрузка исторических погодных данных через Open-Meteo API;
- работа с произвольной локацией и диапазоном лет;
- подготовка данных для обучения;
- многомерная линейная регрессия;
- собственная реализация градиентного спуска;
- стандартизация признаков внутри модели;
- разделение данных на train/test;
- расчёт метрик MAE, RMSE и R²;
- анализ наблюдений с наибольшей ошибкой прогноза;
- Flask-интерфейс для переобучения модели и получения прогноза.

## Данные

Источник данных — Open-Meteo.

Для модели используются три признака:

- `temperature_2m` — температура воздуха;
- `relative_humidity_2m` — относительная влажность;
- `wind_speed_10m` — скорость ветра.

Целевая переменная:

- `apparent_temperature` — ощущаемая температура.

Погодные данные загружаются почасово для выбранных координат
и заданного временного диапазона.

## Модель

В проекте используется собственный класс `GDRegressor`,
реализующий многомерную линейную регрессию.

В отличие от использования готовой модели из `scikit-learn`,
обучение реализовано вручную с помощью NumPy.

В модели реализованы:

- инициализация весов;
- добавление bias;
- стандартизация признаков;
- градиентный спуск;
- прогнозирование;
- восстановление коэффициентов модели в исходном масштабе признаков.

## Обучение и оценка качества

Данные разделяются на обучающую и тестовую выборки.

После обучения рассчитываются:

- **MAE** — средняя абсолютная ошибка;
- **RMSE** — среднеквадратичная ошибка;
- **R²** — коэффициент детерминации.

Дополнительно определяются 10 наблюдений
с наибольшей абсолютной ошибкой прогноза.

Это позволяет не только оценить среднее качество модели,
но и посмотреть, в каких погодных условиях она ошибается сильнее всего.

## Результаты модели

На тестовой выборке модель показала следующие результаты:

- **MAE:** 0.408 °C
- **RMSE:** 0.546 °C
- **R²:** 0.9977

Средняя абсолютная ошибка прогноза составляет около 0.4 °C.

Высокое значение R² показывает, что модель хорошо описывает зависимость ощущаемой температуры
от температуры воздуха, влажности и скорости ветра на используемом наборе данных.

Дополнительно в приложении выводятся 10 наблюдений с наибольшей абсолютной ошибкой,
что позволяет анализировать случаи, в которых линейная модель работает хуже.
